Where to get files
  • Every stock at once: run python luk_scanner.py --universe all --export-data and load luk_scans/luk_data.csv.
  • One stock at a time: Nasdaq.com historical data, Stooq, or TradingView's chart data export. The file name is used as the ticker, and you can rename it below.
  • Needs Date, Open, High, Low, Close and Volume, with at least 130 trading days (a year or more is best).
